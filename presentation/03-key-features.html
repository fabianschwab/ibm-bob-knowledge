Chat interface

Auto-approve

Modes

Plan designs, Agent changes code, Ask explains. Pick the mode that fits your task.

Subagents

Isolated agents that handle a focused task and return only a summary. You approve each one.

Context mentions supported files

Type @ to point Bob at files, folders, errors, terminal output, git changes, or URLs.

Bob tips

Flags with a purple underline and suggests refactorings.

Rollback

You can restore any file or a whole step.

Code actions

Select code to explain it, improve it, or add it to the chat.

Code reviews

Get issues flagged in the Bob Findings panel before you commit.

Commit messages

Commit message from your changes.

Pull requests

Writes the PR title and description from your branch, using your PR template.

Literate coding

Write instructions in the file, then generate and review an inline diff.

Skills

BobalyticsEnterprise plan only
