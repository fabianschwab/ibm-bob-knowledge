Context Window Management — Context Hygiene

Targeted @ Mentions

Reference specific files or line ranges (@utils.ts:45-67) instead of broad folder dumps (@src). Add context on demand in stages rather than all at once.

Why targeted mentions matter

  • A broad @src mention can inject thousands of lines into the context window in a single turn.
  • Bob reads all injected content on every subsequent prompt — not just the first one.
  • Precise references give Bob exactly the signal it needs with minimal token cost.

Mention syntax

  • @filename.ts — entire file (use sparingly for small files only).
  • @filename.ts:45-67 — specific line range (preferred for large files).
  • @folder/ — full directory listing (high token cost; avoid unless necessary).

Staged context strategy

  • Start with a minimal reference — the function signature or the specific lines in question.
  • If Bob asks for more context, add the next relevant section only.
  • Avoid pre-emptively dumping the entire module "just in case".
