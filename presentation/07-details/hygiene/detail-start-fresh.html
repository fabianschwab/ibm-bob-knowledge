Context Window Management — Context Hygiene

Start Fresh (+)

Start a new task when switching topics or when a conversation stalls. This clears poisoned or bloated messages while preserving project files, rules, and skills on disk.

When to start fresh

  • Switching to a different feature, bug, or codebase area mid-session.
  • Bob starts producing drift-y or inconsistent responses after many turns.
  • You've pasted large amounts of log output and want a clean slate.
  • The context indicator shows you are in the caution zone (> 100k tokens).

What is preserved

  • All files on disk — source code, configs, test fixtures.
  • AGENTS.md and all rule files in .bob/rules/.
  • Custom modes defined in .bob/custom_modes.yaml.
  • Installed skills and MCP server configurations.

What is cleared

  • The entire message transcript — every prompt, response, and tool output.
  • Any context you added with @ mentions or clipboard pastes during the session.
