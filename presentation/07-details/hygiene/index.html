Context Window Management

Context Hygiene & Best Practices

Four habits that keep your context window lean, reliable, and productive.

1. Start Fresh (+)

Clear poisoned messages by starting a new task — files and rules on disk are preserved.

2. Targeted @ Mentions

Reference specific files or line ranges instead of broad folder dumps.

3. Use Subagents

Delegate repo-wide exploration to subagents — only the condensed summary enters your main context.

4. Trust Tests Over Text

Keep AGENTS.md short. Point Bob at runnable test suites rather than long chat debates.
