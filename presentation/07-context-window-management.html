Context Window Management

Working memory optimization, token breakdown, and best practices.

The context window is the working memory (~270,000 tokens). Understanding what consumes your window is essential for peak output quality.

Context Risks & Failure Modes

Context Poisoning

Bad input treated as ground truth, causing reasoning drift.

Lossy Condensation

Critical details permanently dropped when the window fills up.

Transcript Bloat

Large dumps consume token headroom and increase latency.
Context Hygiene & Best Practices

Start Fresh (+)

Clear a stale conversation without losing files or rules.

Targeted @ Mentions

Reference specific lines, not whole folders.

Tasks for Subagents

Isolate exploration — only the summary returns to your window.

Trust Tests Over Text

Point Bob at runnable tests, not long chat explanations.
