Key features

Pull requests

Bob analyzes your branch changes, commit history, and branch name to write a PR title and a detailed description. You review and edit the result before the PR is created, all without leaving your IDE.

Before you start

  • Your changes must be committed to a branch.
  • You need push access to the remote repository.

Start the flow

  • Click the PR icon in the Source Control panel.
  • Search for Bob: Create Pull Request in the Command Palette.
  • Type /create-pull-request in the Bob chat.

What happens next

  • Select the base branch. Bob suggests the three most likely ones.
  • Select the remote repository if you have more than one.
  • Review the generated title and description. Confirm them, or type feedback and Bob regenerates them.
  • Bob creates the PR and posts the link in your chat.

Good to know

  • Bob detects your project's PR template, such as .github/pull_request_template.md, and asks you to choose if it finds several. Without one, it uses a built-in template.
  • Descriptive branch names lead to more accurate descriptions.
