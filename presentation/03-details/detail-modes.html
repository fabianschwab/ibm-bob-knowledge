Key features

Modes

Modes are specialized personas that tailor Bob's behavior to your task. Each mode has different capabilities and access levels, so you get the right kind of help and avoid unintended changes.

Built-in modes

  • Agent: Write, modify, and refactor code. Use it to implement features, fix bugs, and create files. It has full tool access.
  • Plan: Analyze requirements and design implementation steps before coding. Use it for new projects and complex features.
  • Ask: Get explanations and answers about your code without making changes.

Switch modes

  • Dropdown: Use the selector left of the chat input.
  • Shortcut: ⌘ + . on macOS or Ctrl + . on Windows and Linux cycles through the modes.
  • Suggestions: Click the mode switch suggestions Bob offers.
  • Automatically: Bob can switch mid-task, for example from Plan to Agent once a plan is ready.

Choosing a mode

  • Start with Plan for new projects or complex features.
  • Use Agent for any task that modifies files.
  • Switch to Ask when you only need information.
  • You can customize modes or create your own with custom modes.
