Key features

Auto-approve

By default, Bob asks for approval before each action. Auto-approve lets Bob run chosen actions without asking, which removes repetitive prompts but bypasses your safety check.

What you need to know

  • Where to set it: Select the Permissions button beside the mode selector at the bottom of the chat input.
  • Per action: Choose which actions Bob may complete on its own. Task-level overrides apply to the current task only.
  • Default behavior: Approval prompts appear one at a time, and you can edit a proposed terminal command before approving it.

Risk levels

  • High: Edit (create, change, and delete files) and Execute (run terminal commands).
  • Medium to high: MCP, which depends on what the connected servers can do.
  • Medium: Read and Skill.
  • Low: Todo, Subtask, Subagent, and Mode.

Stay safe

  • Start restrictive: Begin with minimal permissions and add more only as needed.
  • Use it locally: Good for repetitive tasks, batch operations, and local development.
  • Never in production: Turn it off for sensitive code and production systems.
  • Review regularly: Check what Bob has changed, especially file edits.
