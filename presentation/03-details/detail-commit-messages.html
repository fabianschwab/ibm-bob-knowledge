Key features

Commit messages

Bob examines your staged or unstaged changes, your branch name, and your recent commit history. It then writes a commit message that follows conventional commit standards and matches your project's style.

How to use it

  • Click the sparkle icon next to the commit message box.
  • Review the message Bob generates.
  • Click the sparkle icon again for an alternative suggestion, or edit the message yourself.
  • Commit your changes.

Tips for better results

  • Stage first: It isn't required, but staging groups related changes and makes the message more accurate.
  • Commit atomically: Keep each commit to a single concern.
  • Name branches well: Include the issue number in the branch name when you work on a specific issue.
  • Edit freely: Add details to the generated message, or regenerate if it misses your changes.
