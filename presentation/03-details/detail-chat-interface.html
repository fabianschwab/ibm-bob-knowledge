Key features

Chat interface

The chat interface is your primary workspace in Bob IDE. You describe tasks in natural language, and Bob responds with explanations, file edits, and commands for you to review.

What you need to know

  • Input field: Type your task in plain language, or type / to use slash commands such as /review and /init.
  • Mode selector: The dropdown left of the input field sets which mode Bob works in.
  • Action buttons: Approve or reject Bob's proposed actions above the input field.
  • Auto-approve toolbar: Enable auto-approval for specific actions to speed up your workflow.
  • Header buttons: Start a new chat or open settings.

Write effective prompts

  • Be specific: "Fix the bug in calculateTotal that returns incorrect results for negative numbers" beats "Fix the code."
  • Provide context: Use @ mentions to point to files and code sections.
  • Break down tasks: Submit complex work as smaller steps, one focused request at a time.
  • Review the output: Check Bob's results against your requirements.

Good to know

  • File paths and URLs in the chat history are clickable.
  • Press Enter to send and Shift + Enter for a new line.
  • Search the current task with ⌘ + F or Ctrl + F while the chat panel is focused.
  • Completed tasks are deleted after 14 days by default. Change this under Settings → Chat → Task retention.
