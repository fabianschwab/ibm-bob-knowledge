Key features

Context mentions

Type @ in the chat to reference parts of your project directly. This replaces copying and pasting code or describing where files are.

Mention types

  • File: @/path/to/file.ts includes the file contents. Add line numbers such as @/src/app.js:10-20 for a section.
  • Folder: @/path/to/folder includes the files directly in the folder, not subfolders.
  • Problems: @problems includes errors and warnings from the Problems panel.
  • Terminal: @terminal includes the last command and its output.
  • Git: @git-changes adds uncommitted changes, and a commit hash such as @a1b2c3d adds that commit.
  • URL: @https://example.com imports a web page as Markdown.

Supported file formats

Text & Code Any plain-text file — no extension restrictions
Web & Frontend
.html.css.scss.js.jsx.ts.tsx.vue.svelte
Backend & Systems
.py.go.java.kt.rs.rb.php.cs.c.cpp.swift.sh.ps1
Data & Config
.json.yaml.toml.xml.csv.env.sql
Docs & Markup
.md.mdx.rst.tex.txt.log
Images
.png.jpg.gif.webp
Visual analysis — text, layouts, UI, diagrams
Office
.docx.xlsx.pptx
Structured extraction of text, tables, slides & formulas
PDF
.pdf
Direct reading & text extraction
Not supported
.dll.zip.mp4.mp3.psd
Binaries, archives, audio/video & proprietary formats

How to use them

  • Type @ to open suggestions, keep typing to filter, and select with Enter.
  • Combine several mentions in one request, such as "Fix @problems in @/src/component.ts".
  • Highlight code and press ⌘ + L to add it to the chat.

Good to know

  • File and folder mentions bypass .bobignore and .gitignore.
  • Large files may be truncated, and binary files are not supported.
  • Watch the context window limit when mentioning large folders.
