Key features

Code actions

Code actions give you quick access to Bob from the editor. Bob automatically receives the file path and line numbers, so you don't copy and paste code into the chat.

Available actions

  • Add to Bob Context: Adds the selected code to your conversation with its location, such as @myFile.js:15:25.
  • Explain with Bob: Asks Bob to explain the selected code.
  • Improve with Bob: Asks Bob to suggest improvements to the selected code.
  • Inline Chat: Opens a chat at your cursor so you can stay in the editor. Press ⌘ + K or Ctrl + K.
  • Move to Chat: Sends the selected code to the chat panel. Press ⌘ + L or Ctrl + L.

How to open them

  • Lightbulb: Select code and click the lightbulb icon in the editor gutter.
  • Context menu: Right-click the selected code and choose Bob.
  • Command Palette: Press ⌘ + Shift + P or Ctrl + Shift + P and type "Bob".

Good to know

  • Actions appear when you select code or place the cursor on a line with an error, warning, or hint.
  • The Command Palette applies actions to your current active chat task if one exists.
