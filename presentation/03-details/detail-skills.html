Key features

Skills

Skills are reusable instruction sets, like recipes, that teach Bob a specialized workflow. Bob follows them the same way every time, for tasks such as code reviews, testing, or documentation.

Create a skill

  • Create a folder in .bob/skills/ in your project, or in ~/.bob/skills/ for a global skill.
  • Add a SKILL.md file with YAML front matter containing name and description.
  • Write the instructions below the front matter as clear, actionable steps.
  • Add optional supporting files such as checklists, templates, and scripts next to it.

How skills run

  • Bob decides when to activate a skill based on your request and the skill's description. A skill without a description is ignored.
  • Skills load once per conversation.
  • Bob asks for your permission first. To skip this, turn on Skills in the Auto-Approve settings.
  • If a project skill and a global skill share a name, the project skill wins.

Tips

  • Write a precise description, such as "Review code for bugs, security issues, and best practices".
  • Keep each skill focused on one task, and put detail into supporting files.
  • Commit project skills to version control to share them with your team.
  • The Skills tab in Bob Settings shows which skills are loaded.
