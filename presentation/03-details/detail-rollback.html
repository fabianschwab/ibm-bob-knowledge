Key features

Rollback

Rollback lets you try AI-suggested changes safely. Bob captures file snapshots during a task, separate from your version control, so you can always undo unwanted edits.

What you need to know

  • Automatic snapshots: Bob records one when a task begins and before every file modification.
  • Task-scoped: Each snapshot belongs to a single task.
  • Built into the chat: Rollback controls appear directly in the chat history.

How to use it

  • See what changed: Expand the Changed files view after Bob edits files, use Show all, or click a file to see its diff.
  • Undo to a message: Hover over a user message and click the rollback button to restore files to their state before that message.
  • Undo one file: Click the rollback button on a file in the Changed files view.

Limitations

  • Only changes made during Bob tasks are captured. Manual edits and other tools are not.
  • Restoring overwrites any unsaved changes in your workspace.
  • Files ignored by .gitignore, build folders, binaries, and .env files are excluded.
  • Snapshots accumulate and use memory. Delete old task conversations to free it.
