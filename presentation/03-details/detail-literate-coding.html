Key features

Literate coding

Write natural language instructions, pseudocode, or partial code directly in your source file, right where the code should go. Bob replaces them with real code and shows an inline diff for you to review.

How to use it

  • Turn it on: Press ⌘ + I or Ctrl + I, or click the magic wand icon in the editor toolbar.
  • Write instructions: Your text appears in blue, which marks it as literate coding content.
  • Generate: Press ⌘ + Enter or click Generate. Bob analyzes the whole file and its context.
  • Accept or reject: Accept with ⌘ + Enter, reject with ⌘ + Shift + Backspace. Changes are written to the file before you accept, so you can test them first.

Tips

  • Be specific, and include details such as variable types and function parameters.
  • Split complex logic into smaller, focused blocks.
  • Use it to create new code and to modify existing code.

Current limitations

  • It works on one file at a time. Multi-file support is planned.
  • It is a preview feature, so styling, diffing, and AI behavior are still improving.
