Key features

Code reviews

The built-in Review workflow runs in your IDE. Bob reviews the diff between the branches you select and flags potential issues before you commit, so you can address reviewer comments early.

Run a review

  • Open the panel: Type /review in the chat or use the Review panel icon in the sidebar.
  • Pick a branch to compare: Choose your current, default, remote, or any local branch.
  • Include local work: Toggle Include Uncommitted Changes to review changes you haven't committed.
  • Check an issue (optional): Select a GitHub issue to confirm your changes meet its requirements.
  • Start: Click Start Review. Reviews run with auto-approval.

Work with the findings

  • Findings appear in the Bob Findings panel. Click one to see details and the annotated code.
  • Fix with Bob creates a task to fix the issue. Dismiss removes a finding that isn't relevant.
  • Type @problems in the chat to resolve several issues at once.

Good to know

  • Branch comparison works with GitHub and GitLab. Issue validation requires GitHub.
  • Exclude files such as tests or generated code with glob patterns under Settings → Bob Findings → Review Exclusions.
  • Use Bob's review as a first pass before human review.
