More info

Why AGENTS.md exists

  • LLMs are stateless — each new conversation starts with no memory of previous interactions. Without explicit context, Bob must re-discover the codebase every time.
  • /init solves this — it scans the project once and writes a structured summary Bob reads at the start of every conversation.
  • Manually editable — add business rules, deployment conventions, or team practices that an automated scan wouldn't capture.
  • Re-run after major changes — new modules, new frameworks, structural refactors, or when onboarding new team members.

Mode-specific context

  • Each mode gets its own file — /init generates a dedicated AGENTS.md for Agent, Plan, and Ask modes inside .bob/.
  • Targeted context — Plan mode emphasises architectural conventions; Agent mode highlights file structure and naming patterns.
  • Extends the main file — mode-specific files add to the root AGENTS.md, not replace it.

Tips & best practices

  • Commit AGENTS.md to version control — it is a team artefact that gives every contributor identical project context.
  • Keep entries actionable and concise; exhaustive documentation belongs in referenced files, not in AGENTS.md itself.
  • Re-run /init after adding new services, changing directory structure, or adopting new technologies.
