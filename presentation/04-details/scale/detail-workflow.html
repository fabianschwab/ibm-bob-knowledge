Workflow

What they are

Workflows are pre-defined, curated, multi-step processes built into Bob for specific recurring tasks. They run a structured sequence of steps that Bob follows deterministically — not improvised from a prompt, but executed from a fixed playbook.

  • Each workflow has named, ordered steps with guided interaction at key decision points.
  • Backed by the start_workflow tool internally.
  • Currently built-in: Create PR — selects branch, picks remote, generates description, creates the PR, and returns the link.

How to use them

  • Type /create-pr in the Bob chat — Bob walks you through each step interactively.
  • Bob also starts a workflow automatically when your plain-language request clearly matches a workflow's purpose.
  • Enable or restrict workflow access per mode via the workflow permission group in .bob/custom_modes.yaml.
  • Bob detects and applies your existing PR templates automatically when generating descriptions.

Trigger

  • Slash command: Type /create-pr (or the relevant slash command) directly in the chat input.
  • Command palette: Cmd + Shift + P → search "Bob: Generate PR".
  • Source Control panel: Click the PR icon to launch the workflow from the sidebar.
  • Natural language: Bob recognises intent and starts the workflow automatically when the request matches.
