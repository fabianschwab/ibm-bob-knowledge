Customizing Bob

Scale

Run structured, multi-step execution across your codebase.

Subagents

Subordinate Bob instances with isolated context windows. Delegate focused tasks and receive only a compact summary back.

Workflow

Pre-defined, curated multi-step processes for recurring tasks — triggered by slash command, UI, or natural language.

Hooks

Event-driven automation that runs shell commands or HTTP calls at lifecycle points — no AI involved, no manual trigger.
