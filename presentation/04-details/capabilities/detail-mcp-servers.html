Customizing Bob — Capabilities

MCP Servers

The Model Context Protocol is a standard that lets Bob connect to external systems. Once an MCP server is configured, Bob discovers its tools automatically and can use them as naturally as any built-in capability.

MCP config example & file locations

.bob/mcp.json JSON 
{
  "mcpServers": {
    "local-server": {
      "command": "node",
      "args": ["server.js"],
      "env": {            ← secrets here
        "API_KEY": "your_api_key"
      },
      "alwaysAllow": ["tool1"]
    },
    "remote-server": {
      "type": "streamable-http",
      "url": "https://your-server/mcp"
    }
  }
}

More info

What you can connect

  • Databases — query and write to SQL or NoSQL stores directly from a conversation.
  • Ticket and project systems — read and create issues, link work to code changes.
  • Browsers — automate web interactions, scrape content, or run end-to-end tests.
  • Internal APIs — call proprietary services, enterprise platforms, or custom tooling.

Transport types

  • STDIO (local): Bob launches the MCP server as a child process. Use command, args, and env fields. Best for developer tools and CLI-based integrations.
  • Streamable HTTP (remote): Bob connects to a running server over HTTP/HTTPS using a url field. Best for shared services, enterprise systems, and cloud APIs.

Secrets & security

  • Pass API keys and tokens via the env object — never hardcode credentials as literal strings in the config file.
  • Keep mcp.json files that contain real secret values out of version control; commit only a sanitised template.
  • Local MCP servers run with the same permissions as Bob and can access your file system — only install servers from trusted sources.
  • External MCP servers may send your data to third-party services; review their data handling policies before use.

Tips & best practices

  • Disable unused MCP servers to reduce token usage — Bob removes all MCP definitions from the system prompt when a server is off.
  • Use alwaysAllow to auto-approve specific tools you trust, avoiding repeated confirmation prompts.
  • If an HTTP server times out, set "protocolNegotiation": "legacy" to skip the discovery probe.
  • Ask Bob to scaffold a new MCP server for you: "Create an MCP tool that gets the current Bitcoin price."
