Customizing Bob — Capabilities

Tools

Tools are the actions Bob can take. The model only produces text; a tool call is how that text becomes a real action — reading a file, editing code, running a command, or calling an external service. Every other customization either decides which tools Bob may use, adds new ones, or shapes how it uses them.

What tools do

  • Read — inspect files, directories, and code symbols to understand your project.
  • Edit — create and modify files, optionally restricted to certain file patterns.
  • Execute — run terminal commands such as builds, tests, and git operations.
  • MCP — call tools provided by connected MCP servers: databases, APIs, ticket trackers.
  • Orchestrate — load skills, track todos, start workflows and subtasks, spawn subagents, and switch modes.

How tools fit into customization

Controls access

Custom modes

Allow or deny each tool group per persona. Edits can be limited with fileRegex.

Adds tools

MCP servers

Bring in tools Bob does not have built in, from external systems and APIs.

Guides usage

Skills & rules

Instructions, not tools. They shape how Bob uses the tools it already has.
