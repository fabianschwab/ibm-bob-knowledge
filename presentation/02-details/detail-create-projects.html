What you can do with Bob

Create files and projects

Scaffold new files and entire projects. Bob uses write tools when your request involves creating files, implementing features, fixing bugs, or refactoring code.

Recommended workflow

  • Start with Plan mode: For new projects or complex features, design before implementation and review the plan.
  • Switch to Agent mode: Implement the plan, create files, and make code changes.
  • Run /init: Bob reads your project and generates an AGENTS.md file plus a .bob folder with guidance for each mode.

Write tools

write_file creates new files, apply_diff makes targeted changes, and insert_content adds new lines at a specific position.
