What you can do with Bob

Automate tasks

Streamline repetitive workflows and boilerplate by turning them into reusable building blocks that Bob can run for you.

Ways to automate

  • Slash commands: Create custom slash commands to automate repetitive tasks, run built-in commands, and extend Bob's functionality with simple markdown files.
  • Skills: Reusable instruction sets that teach Bob specialized workflows and tasks for consistent results.
  • Bob Shell: Run Bob in your terminal, including non-interactive sessions for automation scripts and batch processing.
