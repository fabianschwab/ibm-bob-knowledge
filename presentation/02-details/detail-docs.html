What you can do with Bob

Write and update docs

Generate or update documentation from code. Bob reads your files and writes the result back into your project, so documentation stays in step with the code.

Example requests

  • Code comments: "Create JSDoc comments for all functions in @src/helpers.js"
  • Project README: "Create a README.md file for my project based on the code in @src/index.js"

Tip

The more specific your request, the better the results.
