What you can do with Bob

Answer questions

Ask about your codebase and get explanations. Ask mode is built for understanding concepts, analyzing existing code, and getting recommendations without modifying any files.

Ask mode

  • Read-only: Bob analyzes code and explains concepts, and does not switch to implementing code unless you ask.
  • Safe to explore: Prevents unintended file modifications while you focus on learning.
  • Clear visuals: Bob includes Mermaid diagrams when they clarify a response.

Explain code in place

Select code in the editor and use Explain with Bob from the lightbulb menu. Bob receives the file path and line numbers automatically.
