What you can do with Bob

Refactor and debug

Clean up and fix existing code automatically. Bob's code actions give you quick fixes, refactorings, and explanations directly in the editor through lightbulb icons and context menus.

Code actions

  • Add to Bob Context: Adds selected code to your conversation with file path and line numbers.
  • Explain with Bob: Asks Bob to explain the selected code.
  • Improve with Bob: Asks Bob to suggest improvements to the selected code.
  • Inline Chat: Chat with Bob at the cursor position (Cmd + K on macOS, Ctrl + K on Windows and Linux) and accept, reject, or modify the suggestions.

Fix with Bob

Hover over the purple underline in your editor and click Fix with Bob. Bob opens a chat conversation with context about the issue, so you can discuss the refactoring approach and implement the solution together.
